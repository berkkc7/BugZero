# BugZero 🐛

**BugZero** is a Python-based online code editor and execution platform designed to help developers write, run, debug, and understand code.

## 🚀 Features

- Online Python code editor
- Real-time code execution
- Error detection and reporting
- Clear debugging explanations
- Structured execution results
- Secure isolated code execution

## 🛠️ Tech Stack

- **Frontend:** Monaco Editor
- **Backend:** Python, FastAPI
- **Execution Engine:** Isolated Docker containers with gVisor
- **API:** REST API

## 🔒 Security

Security is a core priority of BugZero.

- Isolated code execution
- Server-side execution time limits
- Code-size restrictions
- Restricted network access
- Automatic environment cleanup
- Structured error responses

## 🎯 Project Goal

The goal of BugZero is to make coding and debugging easier by providing a simple, secure, and accessible development environment.

Early development — MVP in progress.
